# 八路列傳

三國題材、歧路旅人式網頁遊戲：八人開局、路徑行動、蓄力 0–3、弱點削盾與崩解。

## 本機開啟

在專案根目錄：

```bash
npm install
npm test
npx tsc --noEmit
npm run build
npm run dev
```

瀏覽器開 `http://127.0.0.1:5177/`。

## 怎麼玩

1. 標題選「開卷」，再選一位英雄動身（八人各有路徑行動與戰技）。第一章都會到新野。
2. 新野城用方向鈕或 WASD／方向鍵移動。靠近人才會出現交談與路徑行動（探聽／挑戰／威嚇／偷竊等）。
3. 先用路徑行動問清楚黃巾弱點，再往城門。官道有伏兵，北營有渠帥。
4. 戰鬥：上方看出手順序。先打弱點削盾（盾圖示列），盾盡則「崩解」、傷害加倍。選指令後再點蓄力珠 0–3，段數隨之增加。
5. 客棧可過夜養傷。列傳選單分頁：道具／狀態／存檔。

## 操作

- 方向鍵／WASD：移動
- Enter：交談
- Esc：列傳選單
- 手機：左下方向鈕、右下交談／路徑行動／列傳（皆 ≥ 44×44）
- 戰鬥：底部指令（攻擊／戰技／防禦／物件）→ 蓄力珠 → 點敵人

## 美術

立繪與場景放在 `public/art/`（例如 `portrait-caocao.png`）。缺圖時以金線暗底字標後備。請勿放入本機絕對路徑。
